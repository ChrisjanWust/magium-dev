# Unit B2-U4 — Book 2, Chapter 5 (both routes)

## Unit focus

**`b2ch5a` has the highest choice density in the entire project: 98 choices across 35 scenes — 2.8
per scene.** Book 2's master flagged it as sweep S1's first target for exactly this reason. By the
time you receive this file, S1 has already replaced sanctioned clown labels across it.

**Your job is the aftermath of that sweep, and it is substantial.** With 98 choices in one file,
there are ~98 echo lines and ~98 NPC reactions that must now be tonally consistent with whatever S1
changed. Work through them systematically:

```sh
grep -n '^choice(\|^ID: ' data/en/b2ch5a.magium
```

For every choice whose label S1 touched, verify three things in the target scene:
1. the **echo line** repeats the new label verbatim
2. the **NPC reaction** still lands (fury, laughter, rebuke) against the *new* line
3. the reaction does not reference a joke that no longer exists

A replaced label with a stale reaction is the most visible possible bug. This is your primary work.

**Secondary — P5.** Both files set `v_b2_ch5_scimitar`. That flag is read in `b2ch8`, `b2ch10b`,
**and Book 3 `b3ch2b`** — it crosses the book seam. If your edits change what acquiring or not
acquiring the scimitar implies emotionally, that is a `CROSS-FILE` item and must be escalated; the
Book 3 master needs to hear about it. `b2ch5a` also reads `v_b2_ch2_deal`, `v_b2_ch2_lessathi`,
`v_b2_ch2_creatures`; `b2ch5b` reads `v_b2_ch2_creatures`, `v_second_book_purchased`,
`v_ch11_saved_rose`.

**`v_second_book_purchased` is a commercial content gate, not a story flag.** Never merge, reorder,
or collapse an `#if` block keyed on it. Prose inside both the purchased and unpurchased variants must
stand independently coherent. Report any edit near it.

**Secondary — P7.** `b2ch5b` averages ~358 words per scene. Stage the short ones.
