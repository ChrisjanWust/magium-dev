# Unit B3-U2 — Book 3, Chapter 2 (all three routes)

## Unit focus

Three routes of one chapter, ~38.6k words. **Three-way variant sweeping is your defining mechanical
hazard.** Near-identical prose will exist in triplicate; fixing one copy and leaving two stale
produces a bug visible only on a specific route. Map the overlap first:

```sh
for f in a b c; do echo "== 2$f scenes=$(grep -c '^ID: ' data/en/b3ch2$f.magium)"; done
diff <(grep '^ID: ' data/en/b3ch2a.magium) <(grep '^ID: ' data/en/b3ch2b.magium)
diff <(grep '^ID: ' data/en/b3ch2b.magium) <(grep '^ID: ' data/en/b3ch2c.magium)
```

Report every multi-variant scene under `VARIANTS SWEPT` with the count updated.

**Primary target — P5.** Route asymmetry is heavy here:
- `b3ch2a` sets `v_b3_ch1_password`, `v_b3_ch2_goblins`
- `b3ch2b` sets `v_b3_ch2_goblins`; **reads `v_b2_ch5_scimitar`** — a **Book 2 seam flag**
- `b3ch2c` reads `v_b3_ch1_password`, `v_b3_ch2_goblins`

`b3ch2c` is a convergence route: it reads two flags and sets nothing. That makes it the file most
likely to have been written as a neutral merge point — the exact shape Pattern 5 exists to catch.
Whatever the player did in `2a`/`2b` must produce a genuinely different emotional register in `2c`,
not merely a different route through it.

**`v_b2_ch5_scimitar` crosses the book seam.** You cannot edit Book 2. If the inbound assumption
looks wrong or your edits change what possessing the scimitar implies, report it as `CROSS-FILE` so
the master can escalate to the operator and the Book 2 master.

**Secondary — P7, white-room dialogue.** `b3ch2b` averages ~541 prose words per scene and `b3ch2c`
~501 — both well above project average. Long scenes are where floating-head exposition lives. With
only 27 and 24 scenes, you can work every one. Anchor conversation in terrain, weather, injury, food,
weapon maintenance, posture. Calibration passages: Master Contract §7.

**Secondary — P3 residue.** `b3ch2b` runs 2.15 choices per scene. Sweep S1 has already replaced
sanctioned labels — verify every echo line repeats the new label verbatim and every NPC reaction
still lands against the new line rather than a joke that no longer exists.

## Do not

- Do not edit `b3ch1`, `b3ch3a`, `b3ch5a`, `b3ch10a`, or any `b2ch*` file.
- Do not change any `choice(...)` label. Sweep S1 owns labels; you own the prose around them.
